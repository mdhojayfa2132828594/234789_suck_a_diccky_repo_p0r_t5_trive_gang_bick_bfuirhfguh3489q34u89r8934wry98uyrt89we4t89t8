Nix Trive — Channel Operations

Internal automation tooling for managing owned YouTube channels.

What this application is

A private automation pipeline that publishes videos to, and manages comments on, YouTube channels owned by the operator. It is not a public product and has no end users other than the account owner.

Google API scopes requested

  • youtube.upload — publish videos to owned channels
  • youtube.force-ssl — read and reply to comments on owned channels

These scopes are used exclusively on channels owned by the operator. No other channel's data is read or modified.

Data handling

The application processes video files, titles, descriptions and comment text belonging to the operator's own channels. No personal data is sold, shared with third parties, or used for advertising. See the Privacy Policy for detail.
